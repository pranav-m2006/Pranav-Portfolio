# Pranav M. — Space-Themed 3D Developer Portfolio

A premium, dark, space-themed 3D interactive portfolio website built for **Pranav M.** (Frontend Developer | AI/ML Practitioner) using React, TypeScript, Three.js, React Three Fiber, GSAP ScrollTrigger, Lenis, and Tailwind CSS.

## 🚀 Key Features

- **Continuous Single-Page Scrolling Structure**:
  - `#home` — **Home / Hero**: Split-screen hero featuring the **3D Futuristic Developer Computer Workstation**, concise bio, and direct scroll CTAs.
  - `#about` — **About Me**: Editorial profile with verified education (SNS College of Engineering), 3 core engineering mindset pillars, and internship history (Thrivels, CodSoft, InternPe).
  - `#skills` — **Skills**: Interactive skill matrix organized by discipline with a live telemetry inspector panel and zero fake percentages.
  - `#projects` — **Projects**: In-depth production case studies for **AI Skill Twin** (with verified Live Demo on Vercel) and **Disaster Management System** (strictly marked as local ML runtime with GitHub repository).
  - `#achievements` — **Achievements**: HackMatrix 3rd Place Podium Finish spotlight, Smart India Hackathon (SIH 2025) National Finalist, 2 Published Patents, and 100-Day LeetCode Streak.
  - `#contact` — **Contact**: Institutional email copy with clipboard feedback, direct GitHub and LinkedIn links, and a client-side inquiry form.
- **Shared 3D Space Background Environment Across The Entire Website**:
  - Over 3,200 twinkling deep space stars and drifting cosmic particles.
  - Realistic distant dark ice planet with illuminated orbital rings and distant moon.
  - Randomized shooting star meteor streaks.
  - Mouse parallax and scroll-linked camera translation for deep continuous 3D perspective.
  - WebGL fallback and reduced-motion compliance.
- **3D Developer Computer Workstation Centerpiece (No Robot)**:
  - Ultrawide curved monitor with detailed developer screen (code editor, file tree, interactive terminal prompt, blinking cursor).
  - Mechanical keyboard with sculpted keycaps and RGB underglow.
  - Ergonomic mouse on an extended minimalist desk platform.
  - Semi-transparent holographic programming panels and orbital data rings.
  - Smooth floating bob, mouse tracking, and screen light projection.
- **GSAP ScrollTrigger & Lenis Smooth Inertia Scrolling**:
  - Smooth synchronized inertia scrolling via Lenis.
  - Staggered entrance animations on every section powered by GSAP and `@gsap/react`.
- **Interactive Cursor Follower**:
  - Custom trailing glow cursor that expands over interactive elements.
  - Automatic detection to disable on touchscreen devices.

## 🛠️ Tech Stack

- **Framework**: React 18 & TypeScript
- **Bundler**: Vite
- **Styling**: Tailwind CSS
- **3D & WebGL**: Three.js, `@react-three/fiber`, `@react-three/drei`
- **Animations & Smooth Scroll**: GSAP, `@gsap/react`, ScrollTrigger, Lenis
- **Icons**: `lucide-react`

## 📦 Scripts

- `npm run dev` — Start the local Vite development server
- `npm run build` — Typecheck with `tsc` and create optimized production build
- `npm run preview` — Locally preview the production build
